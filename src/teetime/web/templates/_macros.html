How the bot picks your tee time
  1. Time slots in rank order. It tries time slot 1 first, and only moves to time slot 2 if nothing in slot 1 is available (then slot 3, and so on).
  2. Inside a time slot, it aims for the middle. For {{ ex.earliest_label }} to {{ ex.latest_label }} the middle is {{ ex.middle_label }}, so it tries:
      {% for t in ex.ranked %}
    1. {{ loop.index }}{{ t.label }}{{ t.offset_text }}
      2. {% endfor %}
    2. and so on, outward from the middle

    Closer to the middle wins, before or after it: {{ ex.ranked[1].label }} ({{ ex.ranked[1].offset_text }}) beats {{ ex.ranked[2].label }} ({{ ex.ranked[2].offset_text }}). When two times are equally close, the earlier one wins.

  3. One tee time per day, upgraded if a better one opens. It keeps checking after it books. If a time in a better-ranked slot, or closer to the middle, opens up before the booking cutoff (4 PM the day before), it switches to it.
