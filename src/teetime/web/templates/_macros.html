How the bot picks your tee time
  1. Time slots in rank order. It tries your time slots in order: slot 1's times first, then slot 2's, and so on. If it ever ends up with a lower-ranked one, it keeps trying for better (step 3).
  2. Inside a time slot, it aims for the middle. Example at Mangrove Bay, where tee times are 7 or 8 minutes apart (other courses space them differently): for {{ ex.earliest_label }} to {{ ex.latest_label }} the middle is {{ ex.middle_label }}, so it tries:
      {% for t in ex.ranked %}
    1. {{ loop.index }}{{ t.label }}{{ t.offset_text }}
      2. {% endfor %}
    2. and so on, outward from the middle

    Closer to the middle wins, before or after it: {{ ex.ranked[1].label }} ({{ ex.ranked[1].offset_text }}) beats {{ ex.ranked[2].label }} ({{ ex.ranked[2].offset_text }}). When two times are equally close, the earlier one wins.

  3. One tee time per day, upgraded if a better one opens. It keeps checking after it books. If a time in a better-ranked slot, or strictly closer to the middle, opens up before the booking cutoff ({{ booking_cutoff_text }}), it switches to it.
